# KSP Generator

Aplikácia na poloautomatickú tvorbu Kontrolných a skúšobných plánov pre stavebné projekty.

## Funkcie
- načítanie technickej správy, rozpočtu, výkresov a referenčného KSP,
- spracovanie všetkých hárkov cenovej ponuky,
- zoskupenie technicky rovnakých položiek a presné sčítanie množstiev v Pythone,
- AI priradenie relevantných kontrol a skúšok podľa referenčného KSP,
- označenie sporných skúšok na odborné overenie,
- export výsledného KSP do Excelu podľa zvolenej mustry.

## Technológie
Python, Streamlit, pandas, openpyxl, Supabase, OpenAI API
